# Pink House

A little window onto the Folkestone coast. Watch the tide, put out some bait, and come back to see what you caught. Every catch can go into your fish book.

一扇通往 Folkestone 海边的小窗。看看潮水，放一点鱼饵，过一会儿回来看看钓到了什么，把收获记进鱼册。

## Play in your browser · 浏览器试玩

On GitHub, open the project website from the repository’s **About** section. Start with **Fishing** to cast a net, or use the weather and tide controls to change the scene. If audio is paused by your browser, click the speaker button.

从 GitHub 仓库的 **About** 区域打开试玩网页。点击 **Fishing** 开始钓鱼，也可以切换天气和潮位。如果浏览器暂停了声音，点击扬声器按钮即可播放。

## Desktop previews · 桌面预览版

Check **Releases** for the Mac build, Windows x64 build, and the Lively Wallpaper package. Each desktop build includes Chinese and English instructions.

在仓库的 **Releases** 区域查看 Mac、Windows x64 和 Lively 动态壁纸版本。桌面包里有中英双语打开说明。

Weather is provided by [Open-Meteo](https://open-meteo.com/). The tide view uses bundled Folkestone predictions when available. Fishing progress is stored locally in your browser.

天气来自 Open-Meteo。潮汐视图在日期覆盖范围内使用内置的 Folkestone 预测。钓鱼进度保存在当前浏览器。
